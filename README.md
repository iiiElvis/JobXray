# JobXray — See through the JD.

[English](README_EN.md) | 中文

面试侦查助手。投简历之前，帮你看清这个机会——你有多对口、面试会被问什么、这个岗位有没有坑。

## 适用人群

| 你是谁 | JobXray 帮你做什么 |
|--------|-------------------|
| 正在投简历的求职者 | 投递前快速扫描这个岗位和你的匹配度，避免盲投 |
| 即将面试的候选人 | 预测面试官会问什么、提前准备应对策略 |
| 拿到面试但对公司不了解的人 | 通过 JD 和公开信息推断公司痛点，帮你在面试中展现主动性 |
| 同时看多个机会的求职者 | 快速扫描每个 JD 的风险信号，筛掉有坑的 |

## 痛点解决

| 传统做法 | JobXray 做法 |
|----------|-------------|
| 凭感觉判断"这个岗位适不适合我" | 逐条对照 JD 要求与简历证据，匹配全貌一目了然 |
| 面试前不知道会被问什么 | 基于你的 gap 和简历疑点，预测针对性面试题 |
| 看完 JD 不知道公司到底缺什么 | 通过 JD 措辞 + 公开信息推断公司真实痛点 |
| 面试时不知道该问什么 | 生成有针对性的反向提问，帮你考察雇主 |
| 分不清 JD 里的正常描述和危险信号 | 系统化扫描7类风险信号，每条引用 JD 原文 |

## Quick Start

1. 安装 Skill：`/install JobXray`
2. 开始对话，JobXray 会自动发送开场白
3. 发送 JD + 简历（文本/图片/PDF 均可）
4. 获得一份包含7个模块的完整扫描报告

## 科学性框架

JobXray 的分析不靠语感，靠规则。

### 匹配判定标准

| 标记 | 判定标准 |
|------|---------|
| ✅ 匹配 | 简历中**明确提及**该技能/经历/资质，有具体证据 |
| ⚠️ 有gap | 简历中有**相关但不完全对口**的内容，或信息不足 |
| ❌ 缺失 | 简历中**找不到任何相关证据** |

### 信息置信度标记

| 标签 | 含义 |
|------|------|
| `[简历原文]` | 简历中直接写明的内容 |
| `[推断]` | 基于简历上下文推测得出 |
| `[未知]` | 简历中没有提供相关信息 |

### 风险等级判定

通过 JD 措辞强度 × 简历覆盖程度交叉确定，不做主观判断：

| | JD 写"必须/要求" | JD 写"优先/加分" |
|---|---|---|
| **简历完全没有** | 🔴 高风险 | 🟡 中风险 |
| **简历有但不完全对口** | 🟠 中高风险 | 🟢 低风险 |

## 不做什么

| 不做 | 为什么 |
|------|--------|
| 重写或优化简历 | 投递阶段用户需要的是看清机会，不是改简历 |
| 综合评分或成功率预测 | 无法科学量化，给了反而误导 |
| 替用户判断"能不能过" | 决策权属于用户，我们只摊开信息 |
| 搜索员工匿名评价 | 非公开信息，不在搜索边界内 |
| 薪资水平对标 | 需要专业数据源，不在当前能力范围 |
| ATS 格式/沟通话术 | 不属于面试侦查的范畴 |

## 搜索边界

公司痛点推断模块会搜索公开信息，但有明确边界：

| 搜 | 不搜 |
|---|------|
| 公司主营业务和业务线结构 | 员工匿名评价（脉脉、Glassdoor） |
| 该方向的近期动态（招聘、产品发布、融资） | 具体薪资数据 |
| 公开的技术博客、产品公告 | 内部组织架构等非公开信息 |

## JD 风险信号扫描类型

| 风险信号类型 | 具体表现 |
|----------|----------|
| 职责模糊 | 核心职责描述空泛，看完不知道具体做什么 |
| 要求过高 | 技能数量和经验年限明显不合理 |
| 边界不清 | 一个岗位覆盖多个角色的工作 |
| 加班暗示 | "抗压能力强"、"快节奏"、"弹性工作"、"创业精神" |
| 薪资异常 | 未标薪资、范围过大、或明显偏低 |
| 高频招聘 | 同岗位反复发布 |
| 权责错配 | 高级职责配初级 title/薪资，或反过来 |

## 真实性原则

- 所有匹配判定基于简历中实际写了什么，不做主观推测
- 每条判定附信息来源标签（`[简历原文]`/`[推断]`/`[未知]`），区分事实与推断
- 风险等级通过框架交叉判定，不凭语感
- JD 风险信号必须引用原文，不凭空猜测
- 公司信息基于公开来源，标注出处
- 搜不到的信息不硬编，退回 JD 文本推断
